# Claptrap

Claptrap is my attempt at a Raspberry Pi-based homelab assistant developed as part of my home IT lab.

The project is intended to provide a central interface for monitoring and interacting with services across the rest of the homelab, while also serving as a practical learning project for Python, Linux, networking, automation and systems administration.

## Current Features

- Interactive command-line interface
- System status monitoring
- Hostname and operating system information
- System uptime
- Memory usage
- Disk usage
- CPU temperature

## Planned Features

- Homelab monitoring
- Proxmox integration
- Windows and Linux server integration
- Home Assistant integration
- Voice commands
- Speech-to-text and text-to-speech
- Automated tasks and API integrations

## Hardware

Currently running on a Raspberry Pi 4 with Raspberry Pi OS Lite (64-bit).
